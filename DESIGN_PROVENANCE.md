# Происхождение визуального решения

Дизайн обновлён 2026-10-18 по запросу пользователя: самостоятельная операционная диспетчерская, графитовый фон и янтарный сигнал, без декоративных звёзд.

Изучены:

- [Comblock](https://www.comblock.ru/) — последовательная крупная типографика, нумерация смысловых разделов и разделение информации на ясные блоки. Использован принцип визуальной иерархии; логотип, тексты, изображения и фирменная графика не переносились.
- [21st.dev Card Table — felipemenezes098](https://21st.dev/@felipemenezes098/components/table-08), demo id 22174 — получен полный TSX через оплаченный connector. Референс структурирования заголовка, строки таблицы, статуса и числовой колонки. React/shadcn код и зависимости не переносились.
- [21st.dev Activity Timeline — olewandowski1](https://21st.dev/@olewandowski1/components/timeline-3), demo id 28340 — получен полный TSX. Изучены направляющая линия, последовательность и отделение времени от события; собственная горизонтальная схема маршрута сделана в HTML/CSS.

Реализация: собственный admin.html, встроенный в Go binary через go:embed. Графика — простая собственная SVG-стрелка и линии, системные шрифты, никаких remote assets. Метрики берутся из реальных API-данных; до подключения показаны тире, а не синтетические показатели. Формы и API-контракты сохранены. Дизайн не является экспортом hosted AI generation 21st.dev.
